## Talk entry template

To add a new talk, create a new file in `/home/runner/work/sdbishoyi.github.io/sdbishoyi.github.io/_talks/` named like:

`YYYY-MM-DD-talk-short-title.md`

with front matter:

```md
---
title: "Talk title"
collection: talks
type: "Invited Talk" # or Contributed Talk / Seminar
permalink: /talks/YYYY-MM-DD-talk-short-title
venue: "Conference or seminar name"
date: YYYY-MM-DD
location: "City, State/Country"
---
```

Then add a short 2–4 sentence summary in the body and optional links to slides/video.
